कियोस्क हार्डवेयर: Windows 10/11 PC + HP LaserJet Pro MFP M126nw
डोमेन: https://msprinter.in

यह गाइड आपकी मशीन (PC) को 24 घंटे चलने वाले स्मार्ट कियोस्क में बदलने के लिए है:

कदम 1: हार्डवेयर कनेक्शन (Hardware Setup)
---------------------------------------
1. अपने कंप्यूटर को HP LaserJet Pro MFP M126nw प्रिंटर से USB केबल द्वारा जोड़ें।
2. HP का आधिकारिक प्रिंटर ड्राइवर (HP M126nw Full Feature Driver) इनस्टॉल करें।
3. Windows Settings -> Devices -> Printers & Scanners में जांचें कि 'HP LaserJet Pro MFP M126nw'
   प्रिंटर 'Ready / Online' दिख रहा है।
4. कंप्यूटर को इंटरनेट (LAN केबल या 4G Wi-Fi डोंगल) से जोड़ें।

कदम 2: कियोस्क 1-क्लिक इंस्टालर चलाएं
---------------------------------------
1. इस फोल्डर में मौजूद 'install_kiosk_machine.bat' फाइल पर माउस से RIGHT CLICK करें।
2. 'Run as administrator' (व्यवस्थापक के रूप में चलाएं) पर क्लिक करें।
3. इंस्टालर अपने आप:
   - C:\MSPrintersKiosk डायरेक्टरी बनाएगा।
   - Windows Sleep और Screen Turn-off को बंद करेगा ताकि मशीन 24 घंटे चालू रहे।
   - Windows Startup में ऑटो-स्टार्ट जोड़ देगा।
   - डेस्कटॉप पर 'Launch MS PRINTERS Kiosk' का शॉर्टकट बनाएगा।

कदम 3: कियोस्क स्क्रीन शुरू करें
---------------------------------------
- डेस्कटॉप पर बने 'Launch MS PRINTERS Kiosk' शॉर्टकट पर डबल क्लिक करें।
- Microsoft Edge या Chrome सीधे Fullscreen कियोस्क मोड में खुलेगा।
- स्क्रीन पर विज्ञापन घूमेंगे और बड़ा QR कोड दिखेगा।
- जब छात्र फोन से वह QR कोड स्कैन करेंगे, तो उनके फोन पर केवल स्टूडेंट प्रिंटिंग पोर्टल खुलेगा!

कदम 4: इमरजेंसी में कियोस्क स्क्रीन बंद करने का तरीका
--------------------------------------------------
- कीबोर्ड पर Alt + F4 या F11 दबाएं।
- या स्क्रीन पर नीचे दाईं ओर सीक्रेट मेंटेनेंस आइकन पर टैप करके PIN '1260' डालें।
